# naira-payroll (synthetic demo)

A small, made-up payroll library written as if in 2025. It exists so InForce
has something to scan: the code, tests, policy page and payslip template
still follow tax rules that were replaced on 1 January 2026.

No real people, salaries or employers. Not tax advice. Do not use it to run payroll.

Run its tests from this folder: `python -m pytest -q`
